# 🎤 Конвертер Аудио в Текст

Простая утилита для преобразования речи из аудиофайлов в текст.

## 📦 Основные зависимости

```
openai-whisper
pydub
```

> Полный список библиотек находится в файле `req.txt`.  
Для установки всех зависимостей используйте команду:

```bash
pip install -r req.txt
```

## 📦 Установка и настройка FFmpeg

Программа использует **FFmpeg** через библиотеку `pydub` для поддержки различных аудио-форматов (например, MP3).

🔗 [Скачать FFmpeg](https://ffmpeg.org/download.html)

### Шаги по установке:

1. Перейдите по ссылке выше и скачайте подходящую версию для вашей ОС.
2. Запустите установщик и следуйте инструкциям.
3. Во время установки убедитесь, что **FFmpeg добавлен в системный PATH**.
4. Проверьте установку в терминале:

```bash
ffmpeg -version
```

Если вы видите информацию о версии — установка прошла успешно.
